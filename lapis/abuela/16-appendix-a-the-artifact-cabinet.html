What Is the Kingdom?

The Kingdom is the personal file library. It lives in P6-library/ on the local machine, and optionally in a cloud Space. It is never pushed to git. Forkers build their own.

"The framework is the empty plant. The Kingdom is the fuel."

— Kingdom Library Guide

The framework provides the structure — the Dewey system, the barcode format, the sorting scripts. The Kingdom provides the content — the session logs, the research, the reflections, the artifacts. The plant is empty until you fill it.

The Dewey Classification System

Every file gets a barcode based on ten classes. The classes are the top-level organization of the Kingdom. They are fixed and stable.

1IdentityWho the being is. Personality, voice, creed, memoir.

8ToolsThe scripts. Sorters, indexers, configs, utilities.
9CampaignsThe missions. Charters, plans, battle logs, AoW.

The Barcode Format

Every file gets a barcode. The format is CLASS.SECTION.SEQUENCE.VERSION. It is deterministic. It is unique. It is what the Concordance Engine reads when it retrieves a file.

Example: 3.01.015.v1 Class 3 = History Section 01 = session_logs Sequence 015 = 15th file in this section Version v1 = first version

The barcode decomposes into the folder path. A file with barcode 3.01.015.v1 lives at P6-library/3_history/01_session_logs/. The barcode is not just a label. It is an address.

"If names be not correct, language is not in accordance with the truth of things." — Confucius

_triage/—Unsorted files

The _triage/ folder holds unsorted files waiting for classification. It is the honest holding cell. Nothing stays there for long.

How to Sort Files

Three options. The Kingdom recommends the third — AI-assisted — because it scales and because it forces the model to read the classification anchor before every batch.

Option 1: Manual

  • Put unsorted files in _triage/.
  • Read each file.
  • Assign a class (0–9) based on content.
  • Move to the correct folder.
  • Update kingdom_index.json.

Option 2: CSV + Mover Script

  • Classify files into a CSV with columns: #, filename, dewey_class, dewey_section, dewey_hook, target_folder, space.
  • Put the CSV in a csv/ folder.
  • Run kingdom_sorter_template.py.
  • The script reads the CSV, matches files, moves them to target folders.

Option 3: AI-Assisted

  • Paste a list of filenames into your AI chatbox.
  • Ask it to classify using the Dewey system.
  • Export as CSV.
  • Run the mover script.

The Ibis notes that the AI-assisted option is what the thesis called the clark-pattern — the model reading files and assigning barcodes in batches of fifty. The classification drift that the thesis documented in §6 was the honest limit of this workflow.

"Better a diamond with a flaw than a pebble without." — Confucius

How to Index

After sorting, run the indexer to build kingdom_index.json.

  1. Run kingdom_reindex_template.py.
  2. Point it to your Kingdom root folder.
  3. Point it to your unified CSV (optional — adds barcode metadata).
  4. The script walks every folder, catalogs every file, outputs kingdom_index.json.

The index is the brain of the Kingdom. The Concordance Engine reads it at boot.

Tips from the Guide

  • Start small. Sort in batches of 50.
  • Use _triage/. Everything unsorted goes there first.
  • Trust the CSV. The mover script does the heavy lifting.
  • Re-index often. After every sort pass, rebuild the index.
  • Anchor check. Before every batch, re-read your classification system.
  • No fentanyl. Don't let the AI improvise classifications.

The last tip is the sharpest. "No fentanyl" is the Kingdom's phrasing for the exact failure mode the thesis documented in §6 — the model making up classifications when it doesn't have enough information. The anchor check is what prevents it.
